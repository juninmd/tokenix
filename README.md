# tokenix

> Local semantic index CLI that slashes LLM token usage by up to 90% — built in Rust, runs 100% offline.

When AI coding assistants like Claude Code, Gemini CLI, or GitHub Copilot need to understand a codebase, they read entire files — burning tokens on code that's completely irrelevant to the task. **tokenix** fixes this by indexing your repository locally (embeddings via [Ollama](https://ollama.com) + SQLite) and intercepting those file reads via a Claude Code hook, returning only the relevant symbols and chunks instead.

```
Without tokenix:  Read(auth/middleware.ts) → 800 lines → ~2,400 tokens
With tokenix:     Read(auth/middleware.ts) → 12 symbols outline → ~180 tokens  ✦ 92% saved
```

---

## Features

- **Semantic search** — finds relevant code by meaning, not just keyword matching
- **AST-aware chunking** — splits by function/class/struct boundaries (Rust, Python, TS/JS, Go)
- **Forced hook interception** — plugs into Claude Code's `PreToolUse` hook for transparent operation
- **Graceful fallback** — if the index is missing or stale (>1h), passes through to the original tool without breaking the session
- **Token budget** — returns chunks up to a configurable token limit (default 3,000)
- **Savings analytics** — `tokenix gain` shows exactly how many tokens were saved per session
- **Single binary** — no Node, no Python, no Docker; one `.exe` / ELF binary via `cargo install`
- **100% local** — embeddings generated by Ollama (`nomic-embed-text`), nothing leaves your machine

## How It Works

```
┌─────────────────────────────────┐
│  Claude Code (PreToolUse hook)  │
│   Read(file)  ─┐                │
│   Grep(query) ─┤  intercept     │
└────────────────┼────────────────┘
                 ▼
       ┌──────────────────┐      ┌──────────────────────┐
       │  tokenix (Rust)  │─────▶│  SQLite + embeddings │
       │                  │      │  .tokenix/index.db   │
       │  • query         │      └──────────────────────┘
       │  • index                         ▲
       │  • hook                          │ embed 768d
       └────────────────────────────────────────────────┘
                                          │
                               ┌──────────────────────┐
                               │  Ollama (local)      │
                               │  nomic-embed-text    │
                               └──────────────────────┘
```

1. **`tokenix index .`** — walks the repo, chunks code by AST symbols, generates embeddings via Ollama, stores everything in `.tokenix/index.db`
2. **Claude Code reads a file** → the `PreToolUse` hook fires `tokenix hook` before the tool executes
3. **`tokenix hook`** checks the index: if the file is large (>200 lines), it returns a symbol outline; if the query looks semantic (3+ words), it returns the top relevant chunks
4. **Claude Code receives the compact context** instead of the raw file — same quality understanding, fraction of the tokens

- **Rust** — for building from source (`cargo install tokenix`)

## Installation

### Option 1: Cargo (recommended)

```bash
cargo install tokenix
```

### Option 2: Build from source

```bash
git clone https://github.com/juninmd/tokenix
cd tokenix
cargo build --release
# Binary at: target/release/tokenix
```

### Setup Ollama model

```bash
ollama pull nomic-embed-text
```

### Install Claude Code hook

```bash
tokenix install-hook
```

This writes to `~/.claude/settings.json`:

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Read|Grep",
      "hooks": [{"type": "command", "command": "/path/to/tokenix hook"}]
    }]
  }
}
```

## Usage

### Index a repository

```bash
cd my-project
tokenix index .
```

```
tokenix indexing /home/user/my-project
  [1/42] src/main.rs
  [2/42] src/auth/middleware.rs
  ...
Done in 38.2s
  Files: 42 indexed, 0 skipped, 0 errors
  Index: 318 chunks, 87,412 tokens stored
```

### Semantic search

```bash
tokenix query "how does JWT validation work"
```

Returns the top relevant chunks (up to the token budget), formatted for LLM consumption.

### Smart file reader

```bash
tokenix read src/auth/middleware.rs         # shows symbol outline for large files
tokenix read src/auth/middleware.rs --symbol validate_token   # shows that function only
tokenix read src/auth/middleware.rs --lines 45-80             # specific line range
```

### Token savings analytics

```bash
tokenix gain
tokenix gain --history   # per-call breakdown
```

```
tokenix gain -- /home/user/my-project

  Passed through     16
  Tokens saved       84,210

By tool:
  Read: 28 calls, 76,450 tokens saved
  Grep: 3 calls, 7,760 tokens saved
```

### Index statistics

```bash
tokenix stats
```

### Remove hook

```bash
tokenix remove-hook
```

## Commands Reference

| Command | Description |
|---|---|
| `tokenix index [PATH]` | Index the repository at PATH (default: current dir) |
| `tokenix query TEXT` | Semantic search over indexed chunks |
| `tokenix read FILE` | Smart file reader with symbol outline |
| `tokenix gain` | Show token savings analytics |
| `tokenix stats` | Show index statistics |
| `tokenix install-hook` | Install PreToolUse hook in Claude Code |
| `tokenix remove-hook` | Remove the hook from Claude Code settings |
| `tokenix hook` | Hook handler (called by Claude Code, not for direct use) |

### `tokenix index` flags

| Flag | Default | Description |
|---|---|---|
| `--model`, `-m` | `nomic-embed-text` | Ollama embedding model to use |
| `--force`, `-f` | false | Reindex all files (ignore mtime/hash cache) |

### `tokenix query` flags

| Flag | Default | Description |
|---|---|---|
| `--budget`, `-b` | 3000 | Max tokens to return |
| `--k` | 20 | Candidate chunks to fetch before budget filter |
| `--file`, `-f` | — | Filter results to a specific file path |
| `--model`, `-m` | `nomic-embed-text` | Embedding model |

## Hook Behavior

The `tokenix hook` command is called by Claude Code before every `Read` and `Grep` tool use. Its decision tree:

```
Index missing or stale (>1h old)?
  → YES: pass through (original tool runs normally)
  → NO:
      Tool is Read?
        File < 200 lines? → pass through
        offset/limit specified? → pass through (targeted read, let it run)
        File ≥ 200 lines? → return symbol outline + exit 2 (block original Read)
      Tool is Grep?
        Pattern < 3 words? → pass through (likely a symbol search, not semantic)
        Pattern ≥ 3 words? → run semantic query + exit 2 (block original Grep)
```

**Exit codes:**
- `0` — pass through, Claude Code runs the original tool
- `2` — block the tool, use hook's stdout as the tool result

## Supported Languages (AST chunking)

| Language | Extensions | Symbol types detected |
|---|---|---|
| Rust | `.rs` | `fn`, `struct`, `enum`, `impl`, `trait`, `mod` |
| Python | `.py` | `def`, `async def`, `class` |
| TypeScript | `.ts`, `.tsx` | `function`, `class`, `interface`, `type`, arrow functions |
| JavaScript | `.js`, `.jsx`, `.mjs` | `function`, `class`, arrow functions |
| Go | `.go` | `func`, `type` |
| Generic | all others | Line-based chunking (400 token blocks) |

## Ignored Paths

tokenix automatically skips: `.git`, `.tokenix`, `node_modules`, `__pycache__`, `.venv`, `venv`, `dist`, `build`, `target`, `.next`, `.nuxt`, `coverage`, `.cargo`, and files matching `.gitignore`.

## Architecture

```
src/
├── main.rs       — CLI entry point (clap), command dispatch
├── chunker.rs    — AST-aware code chunking + outline generation
├── embed.rs      — Ollama HTTP client (embeddings)
├── store.rs      — SQLite storage: files, chunks, embeddings, hook log
├── indexer.rs    — File walker + incremental indexing pipeline
├── query.rs      — Cosine similarity search + result formatting
├── hook.rs       — PreToolUse hook handler (Read/Grep interception)
└── gain.rs       — Token savings analytics
```

**Storage format:** `.tokenix/index.db` — SQLite database with raw `BLOB` embeddings (768-dimensional float32 vectors). Cosine similarity computed in Rust at query time. No external vector DB required.
